## Features

- Home page with all the entries
- Individual entry pages
- Photo Carousel
- Flowers
- Paper theme

## Project Structure

- `index.html` — journal homepage.
- `biodome.html` — Biodome journal entry.
- `placeholderentry.html` — placeholder entry page.
- `style.css` — shared website styles.
- `Images/` — journal photos and decorative assets.
- `CNAME` — custom domain configuration.

## View Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.


## Design 

I designed this to feel like you're reading someone personal physical journal with all the paper elements and flowers.
